# 🫀 أعضاء الجسم | Human Body Organs

منصة تعليمية ويب تفاعلية متكاملة باللغة العربية لاستكشاف أعضاء جسم الإنسان الداخلية (القلب، الرئتان، الدماغ، المعدة، المريء، والعين) بنماذج ثلاثية الأبعاد واقعية، وبنك أسئلة ذكي فوري، وملف إنجاز رقمي قابل للطباعة، وشهادة تميز ذهبية.

## 🌟 المميزات الرئيسية
- 🔬 **مجسم تشريحي ثلاثي الأبعاد 360° لجسم الإنسان (Three.js):** نموذج ثلاثي الأبعاد تفاعلي بالكامل في الصفحة الرئيسية يدعم التدوير الحر في جميع الاتجاهات بالفأرة واللمس، مع شفافية تشريحية للهيكل الخارجي، ونبض ووميض بيولوجي متناغم لوظائف الأعضاء الستة، والتقاط وتكبير ذكي لكل عضو (Raycasting).
- 🧬 **مجسمات ثلاثية الأبعاد طبيعية وواقعية:** مع تفاعل حركة المنظور (3D Parallax Tilt) ونقاط تشريحية تفاعلية (Interactive Hotspots) ومؤثرات حيوية وصوتية.
- 🏷️ **محاكيات تشريحية ذاتية مكتوبة:** مخطط بأسماء الأجزاء ظاهرة، ومجسم ثلاثي الأبعاد، ودليل للأجزاء؛ وعند الضغط على أي جزء يظهر عمله وشرح وافٍ عنه.
- 🎥 **فيديو يوتيوب لكل جزء:** مع إمكانية تغيير الرابط وحفظه من واجهة المستخدم.
- 🎯 **سؤالان لكل عضو مع تحفيز:** تصحيح فوري وشروحات علمية ووسام إتقان، مع إمكانية إضافة أسئلة جديدة.
- 📝 **بنك أسئلة شامل (12 سؤالاً + ما تضيفينه):** يغطي الأعضاء الستة.
- 📂 **ملف إنجاز رقمي (مبتدئ ومطوّر):** توثيق نواتج التعلم وتصدير فوري كـ PDF أو طباعة.
- 🏅 **شهادة تميز وإتمام:** توليد شهادة تكريم ذهبية موثقة باسم الطالب/ـة وتاريخ اليوم والدرجة.
- 🎨 **تصميم مبهج وفاتح باتجاه عربي أصيل (RTL):** متوافق مع كافة أحجام الشاشات والأجهزة اللوحية والسبورات الذكية.

## 🚀 طريقة التشغيل المباشر
فقط افتح ملف `index.html` في أي متصفح إنترنت (Chrome, Edge, Firefox, Safari)، أو ارفعه مجاناً على **GitHub Pages**.
