تصحيح فوري وتوضيح علمي لكل سؤال

كيف تضعين الأسئلة والاختبارات داخل ThingLink مباشرة؟

  1. إضافة سؤال تصويت (Poll Tag): داخل محرر ThingLink، اضغطي على Add tag ثم اختاري Poll واكتبي السؤال وخيارات الإجابة لتظهر كأيقونة تفاعلية نابضة على مجسم العضو.
  2. قفل الانتقال بسؤال (Scenario Branching): إذا كنتِ تستخدمين Scenario Builder، يمكنكِ إضافة عقدة Question node تشترط الإجابة الصحيحة لفتح العضو التالي للطالب.
  3. تضمين نموذج أو سؤال (Embed tag): اختاري Add tag -> Add content from website وضعي رابط السؤال أو الاختبار ليفتح كنافذة منبثقة تفاعلية داخل المجسم.
